# 特殊キーの手動FPS（0.3.42）

「別の値を割り当てる」は異なるFPS/FOVプリセットを別キーへ割り当てるための行追加。同じ行のキー1・キー2は同じ値を使用。

FPSのプリセット選択を維持し、下に手動入力欄（整数1〜300）と設定ボタンを追加。確定前の入力内容ではキー設定を変更しない。無制限は既存プリセットから選択する。カスタム値は選択欄にFPS付きで表示。Rustの保存検証をプリセット限定から0〜300の整数へ拡張（0は無制限）。

匿名FixtureでFPS120/Qを157へ変更し表示・編集マーカーを確認。UIで1/300は有効、301/1.5/0は無効で設定値300を維持する。120へ戻す操作も確認。画像: manual-fps-preview.png。

Rustの回帰テストで全0〜300の生成コマンドと不正値の拒否を確認。JavaScript全32件成功。実際のApex設定への書込みは行っていない。
