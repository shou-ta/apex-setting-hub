# 編集状態とPAD感度の表示（v0.3.30）

## 編集状態

- 保存済みのSnapshotと異なる未適用の変更だけを「編集中」と表示する。
- 各行の「元に戻す」は対応する編集を取り消し、Snapshotへ戻す。ファイルは書き込まない。
- 解像度、画面モード、Reflex、衝撃マーク、色、解像度適応FPSは関連する保存値をまとめて取り消す。
- キー割当は保存時と編集後の両方のアクションに印を付ける。移動元を取り消した場合も、そのキーの保存済み割当へ戻す。
- 区分見出しの件数は、その区分に関連する未適用の編集数。数字ADSと1倍スコープの共有保存値は重複して数えない。非表示のスコープ／ALC設定も含む。
- 区分全体の取消は見出しから実行できる。関連しない編集は維持する。
- 特殊キーの削除は「削除予定」として残し、適用前に取り消せる。

## PAD状態

数字感度／ALCの基礎モード、数字スコープ感度の有効状態、ALCスコープ倍率のオン／オフをController画面とDashboardで表示する。必要なフラグがない場合は「値なし」と表示し、推測で補わない。

ALCがオンの場合、数字の視点感度・ADS・反応曲線・視点操作デッドゾーン・数字スコープ感度の操作を無効化し、理由を添える。保存値は変更しない。数字スコープがオンの場合、通常ADSの変更はスコープ設定の1倍欄から行う。

ALCスコープ倍率のフラグはALC本体と独立して扱い、本体がオフでも操作できる。表示は保存状態と倍率そのもの。現行版の実際のゲーム内効果をこのUI変更で新たに検証したものではない（既存の調査は `setting-audit.md` 参照）。

## 補足説明

「表示のみ」「未対応」「推定対応」「補足」などの短い見出しを置き、詳細な説明・制限・検証状況は展開して読む。未確定の対応や特殊機能の制限に関する説明は削除しない。

## 確認

匿名Snapshotによる画面確認で個別取消、折り畳み後の変更件数、区分全体の取消、ALC使用時の操作制限を確認。自動テストでは複合設定の取消対象、キー移動元と移動先、共有ADSの件数、フラグ全8通りと欠損時の状態を確認。実際のApex設定ファイルへの書込みは行っていない。
